# PetroGulf Vessel Tracking POC — demo package

**Open the demo:** [Launch in WordPress Playground](https://playground.wordpress.net/?blueprint-url=https%3A%2F%2Fraw.githubusercontent.com%2Fmicahharipersad%2Fpetrogulf-vessel-tracking-poc-demo%2Fmain%2FPetroGulf-WordPress-Playground-Demo.zip)

This repository hosts the public Blueprint bundle for a sample-data WordPress proof of concept. The Playground instance is recreated in each visitor's browser; this repository only makes the setup package available at a stable public URL.

## Try it

1. Open the demo link above and wait for WordPress Playground to prepare the site.
2. Enter sample IMO **9987768** and click **Track vessel**.
3. Review the MINTAKA sample vessel card/map and click **Request fuel for this vessel** to see the prefilled enquiry form.

## Important

- The sample AIS position and voyage are illustrative, not live or suitable for navigation or operations.
- The demo uses a test harness; it does not require a real VesselFinder API key.
- Submitting the fuel form does not send an email.
- This is a public repository and its source/package can be viewed or downloaded by anyone.
- It is a demo, not a permanent WordPress hosting service or a production-ready site.
